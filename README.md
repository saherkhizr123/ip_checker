# IP Address Checker

A small Python program that checks whether an entered IP address is valid and identifies it as a private or public IP.

## What it does

* Checks if an IP address is valid
* Supports IPv4 and IPv6
* Shows the IP version
* Identifies private and public IP addresses
* Handles invalid input

## How to run

Make sure Python is installed, then run:

```bash
python ip_checker.py
```

Enter an IP address when asked.

Example:

```text
Enter an IP address: 192.168.1.10

IP Address: 192.168.1.10
Version: IPv4
Type: Private
Used mainly inside local networks.
```

## Concepts used

* Python functions
* User input
* `if/else`
* Exception handling
* `ipaddress` module
* Basic IP addressing

## Note

This is a basic learning project for understanding Python and networking concepts.
